# 街角停車 v1.6

雙北汽車、一般機車與大型重機停車查詢作品：Vue 3、JavaScript、Pug、縮排式 Sass、Pinia、Axios、Leaflet，Node.js 代理官方 API。以深色地圖與側欄操作，並參考「北市好停車」區分路邊格號與停車場剩餘數的方式。自行實作，未使用參考網站程式碼。

## Windows / VS Code 啟動

需要 Node.js 22.12 以上（建議 24 LTS）。在此資料夾開終端機：

```powershell
npm install
npm run dev
```

開啟 http://127.0.0.1:5173/ 。同一指令啟動 Vite 和 8787 的 API 代理。保持終端機執行，Ctrl+C 一起關閉。

正式試跑：

```powershell
npm run check
npm run build
npm start
```

開啟 http://localhost:8787/ 。`npm run preview` 也啟動 Node 伺服器。請勿同時執行 dev 與 preview，以免 8787 埠衝突。

## 官方 API 與限制

完整網址在 `server/sources.mjs`，不需 API Key，不使用第三方共筆資料。

| 官方來源 | 處理方式 | 實際限制 |
|---|---|---|
| 臺北各行政區路邊收費路段資訊 | 下載 API 實際回傳 ODS，解壓讀機車數量欄 | 清冊修改日期 2026/03/27，比今日政策舊，可能缺新收費路段。無行政區、座標，不猜測 |
| 臺北路邊停車格位使用情形 | XML，取一般小型車收費路段 | 車種 2 是大型車，不當成機車。負空位值標未知；座標大多 0，本版不做圖釘 |
| 新北路邊收費停車場收費路段資訊 | JSON 分頁，依 area 的機車收費類別辨識 | 無格位座標，保留官方收費時間 |
| 新北機車停車彎資訊 | JSON 分頁，取板橋、新店一般機車彎 | 缺收費欄位，不標免費；不是全部機車格完整清冊 |
| 新北路邊停車空位查詢 | JSON 分頁，取一般汽車／機車收費格，以及板橋、新店官方明列不收費機車格與座標 | 排除專用格；狀態代碼未完整查證，不解讀即時空位 |

來源筆數是路段與格位混合，可能重複描述同一路段，不能相加當成不重複格位總數。機車空位標「未知」，不使用汽車剩餘數替代。

每次開頁向自己的代理請求官方資料；Node 記憶體快取：汽車／格位 2 分鐘、清冊 1 小時。重新整理在有效快取期間不強迫打官方。沒有包樣本 JSON。來源失敗顯示錯誤；同次執行已有資料時保留並標示。

有官方座標使用 Leaflet / OpenStreetMap；無座標點清單開 Google Maps 地址搜尋嵌入，標示「非官方格位座標」。地址搜尋可能落在道路中段，導航前核對起訖。不做批次地址地理編碼。地圖每個視窗最多顯示 500 個座標點，拖曳地圖重畫當前視窗；請用城市、車種與關鍵字縮小範圍。

## 部署

**需要 Node 伺服器，不能只把 dist 放到 GitHub Pages 或純靜態主機就完成串接。** 新北有 CORS 限制，代理是正式版必需部分。

可執行 Node 的主機：`npm ci` → `npm run build` → `npm start`。正式埠可用 `PORT` 環境變數；反向代理保持網站和 `/api/parking/*` 同來源。只有 PHP 的主機需另外放 Node 代理，或之後另寫 PHP 代理。

未含帳密、API 金鑰或定位權限。地圖連線 OpenStreetMap，地址搜尋連線 Google。保留地圖署名。

## 驗證

`npm run check` 核對免費機車格適用範圍、身障／警用格排除、限時計次收費，以及新北行政區代碼（65000010=板橋，65000060=新店）。`npm run build` 檢查 Vue、Pug、Sass 轉譯。來源格式變更回傳錯誤，不用空陣列冒充成功。

## v1.1 新功能與數字解讀

「路邊／停車場／全部」切換；預設路邊。車種可選汽車、一般機車、大型重機。一般機車顯示普通機車費率，大型重機沿用專屬費率。此資料涵蓋收費路段，未擴充全市免費機車格。

路邊方形「汽／機／重」代表車種；停車場圓形數字表示所選車種剩餘數，沒有動態資料顯示 P。停車場綠色代表滿車率低於 80%、橘色 80% 至未滿 95%、紅色 95% 以上；灰色未知。不是預訂或空位保證。

格號（例如 174）是識別碼，單筆總格數 1。路段總格數與剩餘數分開列示，未知不顯示成 0。選全部車種時，停車場優先顯示汽車，無汽車格才顯示機車／重機，清單及提示會寫車種。

臺北路邊資料無行政區與多數有效座標；選行政區可能只顯示停車場，請用城市和路名搜尋。臺北路外停車場則提供行政區和 TWD97 座標，已轉成 WGS84，無效座標保留地址搜尋。

新增來源：

- 臺北基本：https://tcgbusfs.blob.core.windows.net/blobtcmsv/TCMSV_alldesc.json
- 臺北空位：https://tcgbusfs.blob.core.windows.net/blobtcmsv/TCMSV_allavailable.json
- 新北基本：https://data.ntpc.gov.tw/api/datasets/b1464ef0-9c7c-4a6f-abf7-6bdf32847e68/json
- 新北空位：https://data.ntpc.gov.tw/api/datasets/e09b35a5-a738-48cc-b0f5-570b67ad9c78/json

基本與空位用 ID 合併。動態來源失敗時保留基本資料、空位未知，來源面板顯示警告。停車場來源快取 2 分鐘；新北官方空位約每 3 分鐘更新，重新整理不代表現場沒有變動。

新北空位只提供汽車，不能當作機車或重機空位；臺北 `availableheavymotor` 與 `availablemotor` 分開。大型重機停路外機車格以場方規定為準，路邊開放政策不套到室內／地下場。大型重機篩選只列官方有重機格／明確重機費率者，可能少於實際友善場站。

地下／室內型態由官方名稱、地址與概況的明確字詞辨識。立體另列，並不保證有遮蔽。月租專用或特殊營運限制仍須查場方公告。

新檔案：`server/lots.mjs`（TWD97 與未知值處理）、`src/parking-display.js`（車種空位與總數對應）、`CHANGELOG.md`。

## v1.4 路邊剩餘車位暫時隱藏

路邊列表與詳情暫不顯示剩餘車位欄位，格位編號、單格數及路段總格數仍保留。後端空位欄位仍保留，方便未來查證完整性與可靠性後恢復呈現。路外停車場僅顯示官方提供的剩餘／總格數；未知剩餘數在列表、詳情與地圖提示均隱藏。車種有總格數但無剩餘數時只列總格數，兩者皆未提供則不列該車種。無空位數的地標保留 P，官方 0 格仍顯示 0。

### v1.4 同版補充：逐車種可停資訊

停車場列表及詳情固定列「汽車／一般機車／大型重機」，顯示可停、不可停或官方未標註，詳情保留判定依據。官方場名為機車停車場另加醒目標籤；若僅格數確認汽車 0 格而機車有格，標「機車格停車場」，不將機車場名稱當成大型重機可停證據。

判定使用場站官方格數、費率類型與完整停放說明。臺北 C=小型車、CM=小型車含大型重機、M=機車、HM=大型重型機車；CM 可以確認大型重機使用場方指定汽車格，即使重機專用格是 0。仅有月租／定期費率者註明「臨停未標註」。新北自由文字只寫「重型機車」時，不自行認定為大型重機；必須明列「大型重機／大型重型機車」與費率或可停敘述。

官方完整明列全場禁止才顯示不可停；附帶區域或時間限制的敘述保留未標註並列原文供核對。總格數 0、空位未知或空位 0 均不推定全場禁止共用。路外車種篩選和列表標示使用相同判定，只有可停才列入指定車種篩選。月租、出入時間及停放區仍须看場站完整費率公告。更新後請停止舊 API 程序，再執行 npm run dev。

車種費率欄位來源：https://data.taipei/dataset/detail?id=d5c0656b-5250-4179-a491-c94daa56ef2c 。新檔案：server/vehicle-access.mjs。npm run check 新增 0 格／CM 共用、明確禁止、條件限制、普通與大型重型歧義、跨車種費率、月租限制及機車停車場標註測試。

### v1.4 同版補充：單行色點、月租、身障格與重機停放區

## v1.5：新北完整分頁與 PAYEX 車種證據

新北 API 改以每頁 1000 筆查詢，持續到官方回傳空頁；不再以短頁推定資料結束，避免官方單頁上限導致只讀第一頁。最多查 100 頁；重複頁或非陣列回應視為讀取錯誤，不將不完整結果冒充完整清冊。官方開發指引：https://data.ntpc.gov.tw/applications 。JSON 使用 page／size，完整 CSV 下載可使用 /csv/file。

PAYEX 是官方收費資訊，可能內含汽車、普通機車、重型機車及月租等自由文字。當它列出「重型機車」費率但沒有區分普通／大型時，機車與大重的未確認項目改標「重型機車種類待確認」，詳情與列表提示保留官方原文；仍用黃色，不自行推定大型重機可停或使用汽車格。明確的普通重型、大型重型分別判定；專用格為 0 不等於禁止停放。已有明確格數／費率或全場禁止的項目維持依證據判定。

回歸案例包含林口區停三立體停車場（170009）：TOTALCAR 141、TOTALMOTOR 0，但 PAYEX 有重型機車計時費率；身障月租優惠也不等於身障格數。新增短頁後仍繼續讀取、空頁結束、重複頁與無效格式防護測試。來源同 ID 多筆與 AVAILABLECAR 車種歧義仍需官方澄清，未把該空位欄自行移作機車／大重剩餘數。
